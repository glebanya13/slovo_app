# slovo-app

Слово — Библия, молитвы и спокойные ответы на вопросы веры.

Flutter-приложение, bundle id `dev.davinchi.slovo`. Пакет Dart называется `slovo_app`.

Локальный запуск с ключами:

```sh
flutter run --dart-define-from-file=secrets.json
```

`secrets.json`, `android/key.properties` и keystore в репозиторий не входят.
